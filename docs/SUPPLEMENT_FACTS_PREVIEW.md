# Diagnostic Supplement Facts preview
Recorded 2026-10-12. Development-only, not wired into index.html.

The diagnostic page loads source.js and parser.js, retains raw JSON, and renders supported individual labels with serving references, active names, separate forms, internally consistent declared amounts, population-specific Daily Value text, other ingredients and manufacturer statements. Historical labels receive a prominent warning; missing off-market evidence is not current-market verification. Retrieval date is not a review date. Null DV is not zero. Other-ingredient structured names are not presented as a verbatim sentence when original text is absent. Target-group claims and manufacturer statements remain distinct from certification and evidence findings.

Empty arrays receive an empty-response message, not product-not-found. Unsupported/search responses are not auto-selected. Inconsistent amount/serving values remain unresolved with raw data available. No intake calculations, genetic interpretations, dose limits or safety colors are assigned. Inputs changed during a request clear the old preview and invalidate its displayed response. DOM rendering uses textContent, not label-provided HTML.

The existing parser's 17 assertions passed in the previous batch. This new page has not been browser-tested, phone-tested or verified against additional label formats. Broader malformed-field/schema validation is pending. Normal scanning, Profile and Library remain unchanged.
